# M001-992333 — Research

**Date:** 2026-06-19

## Summary

This milestone establishes a comprehensive set of Jupyter notebooks under `backend/notebooks/` with a shared helper module at `backend/notebooks/utils.py`. The notebooks will demonstrate preprocessing, forecasting (ARIMA/SARIMAX and LSTM), physics-based modeling (2R2C Grey-box and PINN), anomaly detection, and setback control optimization on the real Heat Pump building dataset.

To ensure long-term maintainability and CI integration, all notebooks will be headlessly verified via `backend/tests/test_notebooks.py` using `nbconvert` and `nbformat` executing inside the uv-managed python environment. The shared helper module `backend/notebooks/utils.py` will serve as the single source of data cleaning, clock alignment (to 15-minute intervals), and feature engineering.

## Recommendation

We recommend using `uv` to install the needed modeling and scientific dependencies in the backend virtual environment, and organizing the implementation in 6 sequential notebooks corresponding to the slices. 

Each notebook will run self-contained modeling code by importing data-loading and preprocessing features from `backend/notebooks/utils.py`. The 2R2C physics-informed model will be calibrated using `scipy.optimize.minimize`, and both the PINN and the LSTM/Autoencoder models will be built in PyTorch. The automated integration runner (`test_notebooks.py`) will execute all notebooks programmatically using the nbconvert preprocessor to prevent regressions.

## Implementation Landscape

### Key Files

- `backend/notebooks/utils.py` — Common utility module containing functions for CSV parsing, 15-minute clock resampling, interpolation, time/weather feature engineering, and occupancy heat gain calculations.
- `backend/notebooks/01_preprocessing.ipynb` — Loads raw snap/intervals/power draw datasets, aligns timestamps, handles missing data, and outputs clean normalized files.
- `backend/notebooks/02_forecasting_sarimax.ipynb` — Statistical temperature forecasting using `statsmodels.tsa.statespace.sarimax.SARIMAX` and records RMSE/MAPE.
- `backend/notebooks/03_forecasting_lstm.ipynb` — Deep learning forecast model (L1 base prediction LSTM + L2 error corrector) implemented in PyTorch.
- `backend/notebooks/04_physical_modeling.ipynb` — Parameter calibration of a 2R2C lumped parameters thermal network and a PyTorch PINN formulation.
- `backend/notebooks/05_anomaly_detection.ipynb` — Unsupervised anomaly detection (Isolation Forest, One-Class SVM, and PyTorch Autoencoder) identifying sensor drifts and Modbus error registers.
- `backend/notebooks/06_energy_controls.ipynb` — Simulates dynamic clothing-adjusted comfort setpoints, occupancy heat gains, and setback strategies to estimate kWh energy savings.
- `backend/tests/test_notebooks.py` — Programmatically executes all 6 notebooks to assert zero execution exceptions.

## Don't Hand-Roll

| Problem | Existing Solution | Why Use It |
|---------|------------------|------------|
| Statistical Forecasting | `statsmodels.tsa.statespace.sarimax.SARIMAX` | Industry-standard implementation of SARIMAX models with full parameter estimation and diagnostic capabilities. |
| Grey-Box Optimization | `scipy.optimize.minimize` | High-quality non-linear parameter estimation algorithms (e.g., L-BFGS-B) suitable for 2R2C calibration. |
| Deep Learning / PINN / Autoencoder | `PyTorch (torch)` | Flexible automatic differentiation framework for custom physics loss computation. |
| Anomaly Detection | `scikit-learn` (IsolationForest, OneClassSVM) | Standard, optimized implementations of unsupervised anomaly detection. |
| Notebook Verification | `nbconvert.preprocessors.ExecutePreprocessor` | Programmatically executes notebook cells sequentially in a headless kernel. |

## Constraints

- **Python Version**: Needs Python 3.13 support for PyTorch, scipy, and other ML packages.
- **Dependency management**: All new dependencies must be added to `backend/pyproject.toml` so they are tracked correctly.

## Common Pitfalls

- **Local Minima in 2R2C**: SciPy minimize might find non-physical negative R or C values. Solve this by applying parameter bounds (`bounds=[(0, None), ...]`) and running multiple random restarts.
- **LSTM Sequence Alignments**: Sequence data preparation for LSTM must be carefully aligned so that target predictions do not leak tomorrow's weather features.

## Open Risks

- **PyTorch/Python compatibility on 3.13/3.14**: Some neural network operations might raise deprecation warnings; ensure we use compatible, pinned library versions.
