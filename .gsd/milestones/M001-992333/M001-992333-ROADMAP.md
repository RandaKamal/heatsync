# M001-992333: HeatSync Modeling and Controls Notebooks

**Vision:** Create a comprehensive set of Jupyter notebooks under backend/notebooks/ with a shared helper module backend/notebooks/utils.py illustrating data preprocessing, forecasting, grey-box/PINN modeling, anomaly detection, and energy controls.

## Success Criteria

- All 6 Jupyter notebooks run end-to-end programmatically with zero exceptions.
- Model forecasting metrics (RMSE, MAPE) are generated and logged.
- Anomaly detection flags real sensor issues and Modbus alarm registers.
- Control setback scenarios estimate energy savings in kWh.

## Slices

- [ ] **S01: Data Preprocessing and Shared Utilities** `risk:low` `depends:[]`
  > After this: Reads raw CSVs and outputs normalized 15-min aligned dataframes via utils.py.

- [ ] **S02: Statistical Temperature Forecasting** `risk:low` `depends:[S01]`
  > After this: Runs a SARIMAX forecast model showing temperature trends with validation metrics.

- [ ] **S03: Machine Learning and Two Level Models** `risk:medium` `depends:[S01]`
  > After this: Runs a PyTorch LSTM model and a residual two-level error corrector.

- [ ] **S04: Physical Grey Box and PINN Models** `risk:high` `depends:[S01]`
  > After this: Runs 2R2C calibration and a PINN loss optimizer showing physical consistency.

- [ ] **S05: Anomaly Detection Models** `risk:medium` `depends:[S01]`
  > After this: Identifies sensor anomalies and Modbus error registers with Autoencoder/Isolation Forest.

- [ ] **S06: Energy Controls and Savings Optimization** `risk:medium` `depends:[S01,S04]`
  > After this: Calculates occupancy heat gains and displays HVAC/plug savings from setback strategies.

- [ ] **S07: Automated Notebook Suite Integration** `risk:low` `depends:[S02,S03,S04,S05,S06]`
  > After this: Programmatically executes the full notebook suite end-to-end with zero errors.
